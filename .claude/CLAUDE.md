# Lord of the Dungeon

Unity C# scripts. This repository is a folder inside the Unity project's Assets: Unity makes a `.meta` file for every file you add (commit it), except in folders whose names end with `~` or start with `.`.

## Code graphs

`CodeGraph~/graphs/` draws every line of C# as Mermaid graphs, generated by `CodeGraph~/codegraph.py`. `CodeGraph~/ai/` holds the descriptions (and pictures) the AI writes, shown between the graphs. Details: `CodeGraph~/README.md`.

When you change .cs files:
1. Run `python "CodeGraph~/codegraph.py"`. Never edit `graphs/` by hand.
2. Run `python "CodeGraph~/codegraph.py" todo` and write or update every note it lists in `CodeGraph~/ai/<file>.cs.md`, using the heading lines it prints (they carry the code fingerprint). Keep the first line of a class note short: it is that class's caption on the overview graph.
3. Run step 1 again, then commit the code, `graphs/` and `ai/` together.
4. To show the user what changed: `python "CodeGraph~/codegraph.py" diff` (uncommitted changes) or `diff HEAD~1 HEAD`. `CodeGraph~/out/diff.md` can go into a pull request description.

`AI/` holds code written by the AI. The graphs treat it as external (outside boxes, no pages); see `CodeGraph~/codegraph.json`.
